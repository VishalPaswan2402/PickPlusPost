# 📸 PickPlusPost - Share Your Moments

**PickPlusPost** is a simple and interactive website where users can upload and share images with others. Built using **MERN (MongoDB, Express, React, Node.js)**, this platform allows users to effortlessly share their favorite moments.

**Designed it in learning phase**

---

## 🚀 Features

✅ **User Authentication** – Sign up & login to post images securely.  
✅ **Upload & Share** – Users can upload images and share them publicly.  
✅ **Image Gallery** – View all shared images in a beautiful gallery layout.  
✅ **Responsive Design** – Works on both desktop and mobile devices.  
✅ **Secure Image Storage** – Images are securely stored using **Cloudinary / MongoDB**.  
✅ **Real-Time Updates** – See new posts instantly.  
✅ **Like & Comment** – Engage with other users' posts (future enhancement).  

---

## 🛠️ Technologies Used

- **Frontend**: React.js, Tailwind CSS  
- **Backend**: Node.js, Express.js  
- **Database**: MongoDB (Mongoose)  
- **Image Upload**: Multer & Cloudinary
